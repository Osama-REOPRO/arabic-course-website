## Übung 1 — Gleiche Melodie, unterschiedliche Wurzeln

Nehmen wir ein Muster — **maf3al** (das "Orts-Muster") — und lassen wir verschiedene Wurzeln hindurchlaufen. Beobachten Sie, wie dieselbe "Melodie" jedes Mal ein anderes Wort hervorbringt, die Bedeutung aber immer "ein Ort, an dem ___ passiert" bleibt.

| Wurzel | Arabisch        | Bedeutung der Wurzel | maf3al → Ergebnis | Bedeutung               |
| --- | ------------- | -------------------- | ----------------- | ----------------------- |
| l-3-b | ل-ع-ب | spielen              | mal3ab            | Spielplatz / Stadion    |
| k-t-b | ك-ت-ب | schreiben            | maktab            | Büro                    |
| 3-m-l | ع-م-ل | tun / arbeiten       | ma3mal            | Fabrik                  |
| s-b-7 | س-ب-ح | schwimmen            | masba7            | Schwimmbad              |
| 5-r-j | خ-ر-ج | hinausgehen          | ma5raj            | Ausgang                 |
| w-q-f | و-ق-ف | anhalten / parken    | mawqef            | Parkplatz / Haltestelle |
| 3-r-D | ع-ر-ض | zeigen / ausstellen  | ma3raD            | Ausstellung             |

Beachten Sie: derselbe Rhythmus, dasselbe Vokalmuster, jedes Mal — nur eine neue Wurzel wird eingesetzt, und die Bedeutung passt sich an die neue Wurzel an, während das Gefühl von "Ort" gleich bleibt.

# Hausaufgaben

Für jede Aufgabe ist eine Wurzel mit ihrer Grundbedeutung und ein Muster angegeben. Ihre Aufgabe ist es, die Wurzel in das Muster einzusetzen und das entstehende Wort zu schreiben. Überlegen Sie, was das Muster mit der Bedeutung der Wurzel macht — was für eine Art von Wort entsteht dabei?

> [!NOTE] Hinweis
> In dieser Hausaufgabe existieren **alle** angegebenen Wurzel-Muster-Kombinationen tatsächlich als echte, gebräuchliche Wörter. Sie müssen also nicht prüfen, ob das Ergebnis existiert — es existiert. Konzentrieren Sie sich einfach darauf, die Wurzel richtig in das Muster einzusetzen.

---

## Gelöstes Beispiel
**Wurzel: (5-r-j) — die Idee von "Hinausgehen / Verlassen"**
1. 5-r-j → **fa3al** → ? _(er ging hinaus)_ 
5araj
2. 5-r-j → **maf3al** ? _(ein Ort, an dem X passiert)_
ma5raj

#### lösung
###### 1. 5-r-j > fa3al
Das Muster fa3al hat drei Platzhalter: **f**, **3**, und **l**.
Wir ersetzen sie mit den drei Buchstaben der Wurzel 5-r-j:
- f → **5**
- 3 → **r**
- l → **j**

5-r-j → fa3al → **5araj** _(er verließ / er ging hinaus)_

###### 2. 5-r-j > maf3al
Dasselbe Prinzip, anderes Muster:
- f → **5**
- 3 → **r**
- l → **j**

5-r-j → maf3al → **ma5raj** _(Ausgang)_
