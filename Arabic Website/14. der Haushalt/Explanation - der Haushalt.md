# Schu fi bi 8uraf L Beet? 🏠
*(Was gibt es in den Zimmern des Hauses?)*
fi = gibt

---

## 📚 Hadool 8uraf L Bet
*(Das sind die Zimmer des Hauses)*

| Zimmer       | Arabisch                                |
| ------------ | --------------------------------------- |
| Wohnzimmer   | **8urfet- 2a3det** *(Hay 8urfet 2a3de)* |
| Schlafzimmer | **8urfet- noom**                        |
| Kinderzimmer | **8urfet- wlaad**                       |
| Esszimmer    | **8urfet- 2kel**                        |
| Küche        | **maTba5**                              |
| Badezimmer   | **7ammaam**                             |

---

## ❓ Su2aal: kiif huue / kiif hyye / kiif hinnen + ism ma3rifa
*(Frage: wie ist es? + bestimmtes Nomen)*

> **Misaal (Beispiel):**
> - **kiif huue L Matba5?**
> - ➢ **L Matba5 kbiir.**

> [!note] Jumlet ismiye (Nominalsatz)
> 1. L Matba5 → **mubtada2** (Subjekt)
> 2. kbiir → **5abar** (Prädikat)

### Adjektiv:
**Kbiir - kbiiret - kbaar** *(groß — m/f/pl)* # **z8iir - z8iiret - z8aar** *(klein — m/f/pl)*

### ✅ Übung — S2al/s2ali kiif hiyi/huwe/hinni:

| Kiif hiyi 8urfet (L) Nom?         |     | 8urfet (L) Nom kbire      |
| --------------------------------- | --- | ------------------------- |
| Kiif hinnen L maTba5 w L 7ammaam? | ->  | L Matba5 w L 7ammam kbar. |
| Kiif hyye 8urftii?                | ->  | 8urftii kbiire            |
| kiif hyye 8urfett ahli?           | ->  | 8urfett Ahli kbire.       |
| kiif hinnen 8uraf L beet?         | ->  | 8uraf L beet kbaar.       |
| kiif hinnin L 8uraf?              | ->  | L 8uraf kbaar             |

### 📖 Vokabular — Möbel-bezogene Nomen (Z8ir - z8ire - z8ar):

## 🛋️ Fii: (fi3el d3if) — „Es gibt" (schwaches Verb)

### Möbel:
| Kanabayet | Tawlet | Maktabet | Telfision | Schibbak |
|---|---|---|---|---|
| Sofa | Tisch | Schreibtisch/Bücherregal | Fernseher | Fenster |

**Schu fi bi 8urfet L 2a3det?** *(Was gibt es im Wohnzimmer?)*
➢ **Bi 8urfet L 2a3det fi Kanabeyet, w Tawlet, w Maktabet, w Telvision, w Schibbak.**

---

### ❓ Su2al byballisch bi "Fi" — Ja/Nein-Fragen mit "Fi"

> **Misaal:**
> - **Fi Schibbak bi 8urfet L 2a3det?**
> - ➢ **Eh, fi Schibbak bi 8urfet L 2a3det.**
>
> - **Fi Lambat bi 8urfet L 2a3det?**
> - ➢ **La2, maa fi Lambat bi 8urfet L 2a3det.** *(Lambat = Lampe)*

> [!info] (L) Nafi — Verneinung
> - **muu**: Nafi L ism *(verneint ein Nomen, adjektive)*
> - **maa**: Nafi L fi3el *(verneint ein Verb)*
