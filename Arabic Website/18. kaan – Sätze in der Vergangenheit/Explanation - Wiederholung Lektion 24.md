Eine kurze Wiederholung von Lektion 24, mit einem Beispiel pro Thema. Weiter geht es mit [[Explanation - kaan|Lektion 25: kaan]].

# 1. fii oder bi-?
**bi-** = in, **fii** = es gibt (nur wenn das Ding nicht bekannt ist).
- el-kalb bil-jneenet.
	- الكلب بالجنينة.
	- Der Hund ist im Garten.
- fii kalb bil-jneenet.
	- في كلب بالجنينة.
	- Es gibt einen Hund im Garten.

# 2. Die Endung gehört zum Nomen
mein / dein … hängt immer am Nomen, das Adjektiv bekommt el-.
- qamiiSii el-jdiid
	- قميصي الجديد
	- mein neues Hemd

# 3. Neue Adjektive: weit / eng
waase3 / Dayyeq
- el-qamiiS Dayyeq.
	- القميص ضيق.
	- Das Hemd ist eng.

# 4. Neue Adjektive: schön / hässlich
7eluu / bashe3
- el-fesTaan 7eluu.
	- الفستان حلو.
	- Das Kleid ist schön.

# 5. haad el- = dieser / diese / dieses
haad / hay / hadool + Nomen mit el-
- haad el-fesTaan
	- هاد الفستان
	- dieses Kleid

# 6. Etwas gehört jemandem: la-
X la- Y = X gehört Y
- el-ktaab la-saarat.
	- الكتاب لسارة.
	- Das Buch gehört Sara.

# 7. la- + el- = lal-
- haad el-ktaab lal-bint.
	- هاد الكتاب للبنت.
	- Dieses Buch gehört dem Mädchen.

# 8. Die Frage: la-miin?
Wem gehört …? la-miin kann am Anfang oder am Ende stehen.
- la-miin haad el-ktaab?
	- لمين هاد الكتاب؟
	- Wem gehört dieses Buch?
- haad el-ktaab la-miin?
	- هاد الكتاب لمين؟
	- Wem gehört dieses Buch?

# 9. la + Pronomen: 2ilii, 2ilak …
Mit einem Pronomen wird la- zu 2il- + die Endung, die ihr von 2ism kennt.
- hadool el-banTaloonaatt 2ilii.
	- هدول البنطلونات إلي.
	- Diese Hosen gehören mir.

# 10. Ja oder nein? Und Verneinung
derselbe Satz mit Fragestimme; nein = muu
- haad el-ktaab 2ilak? – la2, muu 2ilii.
	- هاد الكتاب إلك؟ – لأ، مو إلي.
	- Gehört dieses Buch dir? – Nein, es gehört nicht mir.
