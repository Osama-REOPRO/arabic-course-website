# Zu einem Mann / zu einer Frau
- kiifak? (Mann) / kiifek? (Frau)
- tfaDDal! (Mann) / tfaDDalii! (Frau)
- 2anaa mnii7 (ich, Mann) / 2anaa mnii7at (ich, Frau)

# Aussprache
- Sabaa7 el-nuur → „Sabaa7 en-nuur“, masaa el-nuur → „masaa en-nuur“, ma3 el-salaamet → „ma3 es-salaamet“
- lange Vokale am Wortende werden oft kurz gesprochen: mar7abaa → „mar7aba“
