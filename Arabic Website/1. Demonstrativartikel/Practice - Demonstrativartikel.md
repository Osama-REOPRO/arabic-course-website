1) beet (house)

بيت

Arabic: haad beet

هاد بيت

German: Das ist ein Haus.
English: This is a house.

2) Sabii (boy)

صبي

Arabic: haad Sabii

هاد صبي

German: Das ist ein Junge.
English: This is a boy.
With emphasis:
German: Dieser Junge.
English: This boy.

3) rjaal (men)

رجال

Arabic: hadool rjaal

هدول رجال

German: Das sind Männer.
English: These are men.

4) kalb (dog, masculine)

كلب

Arabic: haad kalb

هاد كلب

German: Das ist ein Hund.
English: This is a dog.

5) 3elbet (box, feminine)

علبة

Arabic: hay 3elbet

هي علبة

German: Das ist eine Dose.
English: This is a box.

6) Sabiyyet (girl)

صبية

Arabic: hay Sabiyyet

هي صبية

German: Das ist ein Mädchen.
English: This is a girl.

7) kalbet (female dog)

كلبة

Arabic: hay kalbet

هي كلبة

German: Das ist eine Hündin.
English: This is a female dog.

8) marat (woman)

مرة

Arabic: hay marat

هي مرة

German: Das ist eine Frau.
English: This is a woman.

9) 7ubb (love)

حب

Arabic: haad 7ubb

هاد حب

German: Das ist Liebe.
English: This is love.
