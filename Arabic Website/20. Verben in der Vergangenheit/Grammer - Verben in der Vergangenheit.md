# Nur zwei Formen
- **Vergangenheit** (el-maaDii): katab, er schrieb
- **Gegenwart** (el-muDaare3): yektob, er schreibt
- alles andere kommt von der Gegenwart: byektob, 3am yektob, ra7 yektob

# Die Vergangenheit ist ein Muster
- **fa3al** = er hat es getan: katab, Taba5, fata7, ghasal, daras
- jede Person hat ihr eigenes Muster:

| | Muster | katab | Deutsch |
| --- | --- | --- | --- |
| **2anaa** | fa3alt | katabt | ich schrieb |
| **2inte** | fa3alt | katabt | du schriebst (m.) |
| **2intii** | fa3altii | katabtii | du schriebst (f.) |
| **huwwe** | fa3al | katab | er schrieb |
| **hiyye** | fa3lett | katbett | sie schrieb |
| **ni7naa** | fa3alnaa | katabnaa | wir schrieben |
| **2intuu** | fa3altuu | katabtuu | ihr schriebt |
| **hinnen** | fa3aluu | katabuu | sie schrieben |

> [!NOTE] Achtung: hiyye
> Im Muster für hiyye wandert der zweite Vokal: fa3lett, nicht fa3alett.
> katbett, Tab5ett, fat7ett, ghaslett, darsett

# Sätze
- das Pronomen steckt im Verb: katabt = (2anaa) katabt
- **nicht:** maa direkt vor dem Verb: maa katab
- **Ja / Nein:** 2a5uuk katab? → 2ee, katab. / la2, maa katab.
- **Fragewort meistens zuerst:** shuu katab? / miin katab? / ween katab?
