# Arabische Vokale

| Lang    | Kurz  | Beispiel (lang) |
| ------- | ----- | --------------- |
| aa      | a     | baab            |
| ii / ee | i / e | kbiir / beet    |
| uu / oo | u / o | nuur / yoom     |

- lange Vokale werden **doppelt** geschrieben, kurze Vokale **einfach**
- ii / ee und uu / oo sind **verschiedene Klänge** und nie austauschbar
