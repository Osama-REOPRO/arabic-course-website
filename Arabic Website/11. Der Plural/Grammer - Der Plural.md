# Die drei Pluralarten

Im Arabischen gibt es **drei** Pluralarten

## 1. Der gesunde maskuline Plural

Diese Pluralform fügt **-iin** an das Wort an.

> mwaDDHaf + iin = **mwaDDHafiin** *(Angestellte)*
> suurii + iin = **suuriyyiin** *(Syrer)*


## 2. Der gesunde feminine Plural

Diese Pluralform fügt **-aatt** an das Wort an, nachdem die Endung **-et/-at** (taa2 marbuuTat) entfernt wurde.

> mwaDDHafet → mwaDDHaf + aatt = **mwaDDHafaatt** *(Angestellte, weiblich)*
> sayyaarat → **sayyaaraatt** *(Auto → Autos)*

Vor einem Suffix: -aat- (sayyaaraatnaa).


## 3. Der gebrochene Plural (jam3 taksiir)

Das Wort verändert sich **von innen**: die Vokale ändern sich, das Muster (wazn) ist neu, auch wenn die Konsonanten gleich bleiben.

> walad → **wlaad**
> beet → **byuut**

# Entscheidungshilfe: Welchen Plural benutze ich?

## Stufe 1: Gesunder femininer Plural (-aatt)?

**Endet das Wort auf -et / -at (taa2 marbuuTat/weiblich)?**
**→ Ja** = -aatt
> mwaDDHafet → mwaDDHafaatt / sayyaarat → sayyaaraatt

**Kein -et / -at — ist das Wort ein Lehnwort?**
**→ Ja** = -aatt
> talifoon → talifoonaatt / kambyuutar → kambyuutaraatt

**→ Nein** = Weiter zu Stufe 2.

---

## Stufe 2: Gesunde maskuline Plural (-iin ) oder gebrochener Plural?

Passt das Wort zu einem dieser Muster?
- fängt mit **mu-** an *(meistens ein Beruf: muhandes, mumarreD)*
- endet auf **-ii** *(meistens eine Nationalität oder Zugehörigkeit: suurii, 3arabii)*
- folgt dem **fa33aal**-Muster *(jemand, der etwas beruflich tut: sawwaaq, Tabbaa5, bayyaa3)*

**→ Ja** = -iin
**→ Nein** = gebrochener Plural — einfach mitlernen!

> [!NOTE] Wie Araber es lernen
> Arabische Muttersprachler hängen einfach **-iin** ans Wort und hören, ob es sich richtig anfühlt. Wenn ja — richtig! Wenn nicht — gebrochener Plural.
> Ehrlich gesagt kämpfen auch viele Araber selbst damit — das ist also kein Fehler, den nur Lernende machen.

# Kurz
**1. taa2 marbuuTat (-et/-at)?** → -aatt ✓
**2. Lehnwort?** → -aatt ✓
**3. mu- / -ii / fa33aal?** → -iin ✓
**4. Nichts davon?** → gebrochener Plural — auswendig lernen!
