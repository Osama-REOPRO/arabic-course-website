# Adjektive (el-Sifet w el-mawSuuf)
Ausführlich: [[Explanation - Adjektive|Adjektive]] · weiter: [[Grammer - Adjektive, Besitz, Vergleich, Farben|Lektion 24]]

- das Adjektiv steht **nach** dem Nomen: fesTaan Tawiil (ein langes Kleid)
- es passt sich an in **Genus**, **Numerus** und **Bestimmtheit**:
	- fesTaan Tawiil → el-fesTaan el-Tawiil
	- tannuurat qaSiirat → el-tannuurat el-qaSiirat
	- kanzaatt jdaad → el-kanzaatt el-jdaad

# Plural
- Adjektiv im Plural: kanzaatt **kbaar**
- oder einfach die feminine Singularform: kanzaatt **kbiiret**
- beide Formen sind gleich richtig

# Nominalsatz
- Antwort auf „kiif …?“ (wie ist …?): das Adjektiv bekommt **kein** el-
	- kiif el-fesTaan? → el-fesTaan Tawiil. (Das Kleid ist lang.)

| Frage | Antwort | Deutsch |
| --- | --- | --- |
| shuu haad? | fesTaan Tawiil | ein langes Kleid |
| 2ayyaa fesTaan? | el-fesTaan el-Tawiil | das lange Kleid |
| kiif el-fesTaan? | el-fesTaan Tawiil | Das Kleid ist lang. |

# Ein Nomen bestimmt machen
- mit el-: sayyaarat → el-sayyaarat
- mit einer Endung: sayyaarat → sayyaartii
- mit einer 2iDaafet: sayyaarat → sayyaaret 2a7mad
