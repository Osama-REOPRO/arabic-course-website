# ☀️ Arabische Sonnenbuchstaben Vokabeln

حروف شمسية

> **Hinweis:** Geschrieben wird immer **el-**. Vor diesen Wörtern spricht man das l aber nicht, sondern verdoppelt den ersten Buchstaben: el-shams, gesprochen „esh-shams“.

## Gruppe 1: t, th, d, dh, r, z

ت ث د ذ ر ز

- **taaj** :: Krone
- **tuffaa7** :: Äpfel (Sammelbegriff), oft gesprochen „teffaa7“
- **thoob** :: Gewand / Kleidung, gesprochen „toob“
- **thalj** :: Schnee / Eis, gesprochen „talj“
- **daftar** :: Notizbuch / Heft
- **dars** :: Lektion / Unterricht
- **dhahab** :: Gold, gesprochen „dahab“
- **dhiib** :: Wolf, gesprochen „diib“
- **rijjaal** :: Mann
- **rummaan** :: Granatapfel, oft gesprochen „remmaan“
- **zeet** :: Öl
- **zahrat** :: Blume

## Gruppe 2: s, sh, S, D

س ش ص ض

- **samaket** :: Fisch
- **sayyaarat** :: Auto
- **shams** :: Sonne
- **shajarat** :: Baum
- **Sabaa7** :: Morgen
- **Daw** :: Licht
- **Deef** :: Gast

## Gruppe 3: T, DH, l, n

ط ظ ل ن

- **Taaleb** :: Student / Schüler
- **Tariiq** :: Weg / Straße, gesprochen „Tarii2“
- **DHill** :: Schatten, gesprochen „Zill“
- **DHuhr** :: Mittag, gesprochen „Duhr“
- **laban** :: Joghurt
- **lsaan** :: Zunge / Sprache
- **najmet** :: Stern
- **nahr** :: Fluss, oft gesprochen „naher“
- **nasr** :: Adler
- **noom** :: Schlaf
# 🌙 Arabische Mondbuchstaben Vokabeln

حروف قمرية

> **Hinweis:** Wenn du den bestimmten Artikel **el-** vor diese Wörter setzt, wird das "l" deutlich ausgesprochen (z. B. *el-qamar*, gesprochen „el-2amar“).

## Gruppe 1: 2, b, 7, 5

أ ب ح خ

- **2arnab** :: Hase / Kaninchen
- **2amaan** :: Sicherheit
- **baab** :: Tür
- **ba7r** :: Meer
- **7ubb** :: Liebe
- **7aqiiqat** :: Wahrheit, gesprochen „7a2ii2at“
- **5ubz** :: Brot, oft gesprochen „5ubuz“
- **5ariif** :: Herbst

## Gruppe 2: 3, gh, f, q, k

ع غ ف ق ك

- **3een** :: Auge / Quelle
- **3asal** :: Honig
- **gharb** :: Westen
- **ghazaal** :: Gazelle
- **faraashet** :: Schmetterling
- **fajr** :: Morgendämmerung
- **qamar** :: Mond, gesprochen „2amar“
- **qalam** :: Stift, gesprochen „2alam“
- **ktaab** :: Buch
- **qalb** :: Herz, gesprochen „2alb“

## Gruppe 3: m, w, h, y

م و هـ ي

- **madraset** :: Schule
- **mayy** :: Wasser
- **walad** :: Junge
- **waqt** :: Zeit, gesprochen „wa2t“
- **hawaa** :: Luft / Wind
- **hilaal** :: Sichelmond
- **2iid** :: Hand
- **yamiin** :: Rechte Seite
- **yoom** :: Tag
- **yaasmiin** :: Jasmin
