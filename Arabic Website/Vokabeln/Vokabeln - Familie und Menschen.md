# Familie und Menschen

Jeder Eintrag: **Umschrift** (Wortart) – Deutsch, darunter die arabische Schrift ohne und mit 7arakaatt.

- **2ab** (m.) – der Vater
	- أب
	- أَب
	- Hinweis: 2abii = mein Vater, 2abuuk = dein Vater (unregelmäßig)

- **2umm** (f.) – die Mutter
	- أم
	- أُمّ

- **2ahl** (m.) – die Eltern, die Familie
	- أهل
	- أَهل
	- Hinweis: 2umm + 2ab = 2ahl. 2ahlii = meine Eltern

- **2a5** (m.) – der Bruder
	- أخ
	- أَخ
	- Plural: 2i5waatt
	- Hinweis: 2i5waatt heißt auch „Geschwister“ (2a5 + 2u5t). 2a5ii = mein Bruder, 2a5uuk = dein Bruder (unregelmäßig)

- **2u5t** (f.) – die Schwester
	- أخت
	- أُخت
	- Plural: 2i5waatt
	- Hinweis: 2u5tii = meine Schwester

- **2ibn** (m.) – der Sohn
	- ابن
	- اِبن
	- Hinweis: 2ibn 3ammii = mein Cousin (Sohn meines Onkels)

- **bint** (f.) – das Mädchen, die Tochter
	- بنت
	- بِنت
	- Plural: banaatt
	- Hinweis: bintii = meine Tochter

- **jidd** (m.) – der Großvater
	- جد
	- جِدّ
	- Plural: jduud
	- Hinweis: jiddii = mein Opa

- **sitt** (f.) – die Großmutter
	- ست
	- سِتّ
	- Plural: sittaatt
	- Hinweis: sittii = meine Oma

- **3amm / 3ammet** (m. / f.) – der Onkel / die Tante (Geschwister des Vaters)
	- عم / عمة
	- عَمّ / عَمِّة
	- Plural: 3maam (m.)
	- Hinweis: 3amm für den Onkel, 3ammet für die Tante

- **2ibn 3amm / bint 3amm** (Ausdruck) – der Cousin / die Cousine (väterlicherseits)
	- ابن عم / بنت عم
	- اِبن عَمّ / بِنت عَمّ
	- Hinweis: 2ibn 3amm für einen Cousin, bint 3amm für eine Cousine. Bei der Tante: 2ibn 3ammet / bint 3ammet. 2ibn 3ammii = mein Cousin

- **5aal / 5aalet** (m. / f.) – der Onkel / die Tante (Geschwister der Mutter)
	- خال / خالة
	- خال / خالِة
	- Plural: 5waal (m.)
	- Hinweis: 5aal für den Onkel, 5aalet für die Tante

- **2ibn 5aal / bint 5aal** (Ausdruck) – der Cousin / die Cousine (mütterlicherseits)
	- ابن خال / بنت خال
	- اِبن خال / بِنت خال
	- Hinweis: 2ibn 5aal für einen Cousin, bint 5aal für eine Cousine. Bei der Tante: 2ibn 5aalet / bint 5aalet. wlaad 5aalii = meine Cousins (mütterlicherseits)

- **rijjaal** (m.) – der Mann
	- رجال
	- رِجّال
	- Plural: rjaal

- **marat** (f.) – die Frau, die Ehefrau
	- مرة
	- مَرَة
	- Hinweis: martii = meine Frau

- **jooz** (m.) – der Ehemann
	- جوز
	- جوز

- **Sabii** (m.) – der Junge
	- صبي
	- صَبي
	- Plural: Sibyaan
	- Hinweis: man sagt auch walad

- **Sabiyyet** (f.) – das Mädchen, die junge Frau
	- صبية
	- صَبيِّة

- **walad** (m.) – der Junge, das Kind
	- ولد
	- وَلَد
	- Plural: wlaad
	- Hinweis: wlaad heißt auch „Kinder“

- **Tifl / Tiflet** (m. / f.) – das Kind
	- طفل / طفلة
	- طِفل / طِفلِة
	- Plural: 2aTfaal
	- Hinweis: Tifl für einen Jungen, Tiflet für ein Mädchen. Eher förmlich, im Alltag sagt man wlaad für Kinder

- **rfiiq / rfiiqat** (m. / f.) – der Freund / die Freundin
	- رفيق / رفيقة
	- رفيق / رفيقَة
	- Plural: rifqaatt (m.), rfiiqaatt (f.)
	- Hinweis: rfiiq für einen Mann, rfiiqat für eine Frau. In Damaskus gesprochen „rfii2“

- **7abiib / 7abiibet** (m. / f.) – der Liebling, der Geliebte / die Geliebte
	- حبيب / حبيبة
	- حَبيب / حَبيبِة
	- Hinweis: 7abiib für einen Mann, 7abiibet für eine Frau. 7abiibii = mein Liebling, 7abiibtii = meine Liebe, 7abiibet qalbii = mein Schatz

- **Deef** (m.) – der Gast
	- ضيف
	- ضيف

- **3ammoo** (m.) – Onkel (höfliche Anrede für einen älteren Mann)
	- عمو
	- عَمّو
