# Wurzel & Muster Spickzettel

**Wurzel (jazr)** = trägt die Bedeutung — 3 Konsonanten (meistens), feste Reihenfolge, für sich allein kein echtes Wort.
**Muster (wazn)** = trägt die Funktion — eine Vorlage/"Melodie", in die die Wurzelbuchstaben eingesetzt werden.

Wurzel + Muster → echtes Wort: die Wurzel gibt *worum es geht*, das Muster gibt *was für eine Art Wort* (Zeitform, Ort, Person, Werkzeug, Ergebnis, usw.).

Muster werden mit der Platzhalter-Wurzel **f-3-l** benannt, die für Wurzelbuchstabe 1, 2, 3 steht.

Gleiche Wurzel → viele Muster → verwandte Wörter (schreiben → schrieb / Büro / Schriftsteller / Brief).
Gleiches Muster → viele Wurzeln → gleiche Wortart, andere Bedeutung (Orts-Muster → Büro / Küche / Fabrik).

Nicht jede Wurzel passt zu jedem Muster — manche Kombinationen sind einfach keine echten Wörter.

Dieses System ist das Fundament der arabischen Grammatik, nicht nur ein Vokabel-Trick.
