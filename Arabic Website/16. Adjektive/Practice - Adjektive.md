# Lösungen

## Übung 1
- Das ist ein langes Kleid.
	- haadaa fesTaan Tawiil
- Ein langer Rock.
	- tannuurat Tawiilet
- Ein kurzer Rock.
	- tannuurat qaSiirat
- Lange Kleider.
	- fasaatiin Twaal
- Die langen Kleider
	- el-fasaatiin el-Twaal
- Wo ist das Kleid?
	- ween el-fesTaan
- Welches Kleid?
	- 2ayyaa fesTaan
- Das lange Kleid ist im Schrank.
	- el-fesTaan el-Tawiil bi el-5zaanet
- Die kurzen Röcke sind im Schrank.
	- el-tanaaniir el-qSaar bi el-5zaanet
	- el-tanaaniir el-qSaar bi 5zaantii
	- el-tanaaniir el-qSaar bi 5zaanet 2a7mad

## Übung 2
- Das ist ein neues Hemd.
	- haadaa qamiiS jdiid 
- Eine neue Bluse
	- bluuzet jdiidet
- Ein alter Pullover.
	- kanzet qadiimet
- Neue Blusen.
	- bluuzaatt jdiidet
	- bluuzaatt jdaad
- Wo ist mein Hemd?
	- ween qamiiSii
- Welches Hemd?
	- 2ayyaa qamiiS
- Mein neues Hemd.
	- qamiiSii el-jdiid
- Dein neues Hemd ist in deinem Schrank.
	- qamiiSak el-jdiid bi 5zaantak
