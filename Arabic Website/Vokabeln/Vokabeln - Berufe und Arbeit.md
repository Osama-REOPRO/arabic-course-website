# Berufe und Arbeit

Jeder Eintrag: **Umschrift** (Wortart) – Deutsch, darunter die arabische Schrift ohne und mit 7arakaatt.

- **2ustaadh** (m.) – der Lehrer
	- أستاذ
	- أُستاذ
	- Plural: 2asaatdhet
	- Hinweis: in Damaskus gesprochen „2ustaaz“, Plural „2asaatze“

- **2aanset** (f.) – die Lehrerin
	- آنسة
	- آنسِة
	- Plural: 2aansaatt

- **doktoor / doktoorat** (m. / f.) – der Arzt / die Ärztin
	- دكتور / دكتورة
	- دُكتور / دُكتورَة
	- Plural: dakaatrat (m.), doktooraatt (f.)
	- Hinweis: doktoor für einen Mann, doktoorat für eine Frau

- **Taaleb / Taalbet** (m. / f.) – der Student / die Studentin, der Schüler / die Schülerin
	- طالب / طالبة
	- طالِب / طالبِة
	- Plural: Tullaab (m.), Taalbaatt (f.)
	- Hinweis: Taaleb für einen Mann, Taalbet für eine Frau

- **muhandes / muhandiset** (m. / f.) – der Ingenieur / die Ingenieurin
	- مهندس / مهندسة
	- مُهَندِس / مُهَندِسِة
	- Plural: muhandesiin (m.), muhandesaatt (f.)
	- Hinweis: muhandes für einen Mann, muhandiset für eine Frau

- **murabbii / murabbiyet** (m. / f.) – der Erzieher / die Erzieherin
	- مربي / مربية
	- مُرَبّي / مُرَبّيِة
	- Plural: murabbiyiin (m.), murabbiyaatt (f.)
	- Hinweis: murabbii für einen Mann, murabbiyet für eine Frau

- **mumarreD / mumarreDat** (m. / f.) – der Krankenpfleger / die Krankenschwester
	- ممرض / ممرضة
	- مُمَرِّض / مُمَرِّضَة
	- Plural: mumarreDiin (m.), mumarreDaatt (f.)
	- Hinweis: mumarreD für einen Mann, mumarreDat für eine Frau

- **bayyaa3 / bayyaa3at** (m. / f.) – der Verkäufer / die Verkäuferin
	- بياع / بياعة
	- بَيّاع / بَيّاعَة
	- Plural: bayyaa3iin (m.), bayyaa3aatt (f.)
	- Wurzel: b-y-3
	- Hinweis: bayyaa3 für einen Mann, bayyaa3at für eine Frau

- **7allaaq** (m.) – der Friseur
	- حلاق
	- حَلّاق
	- Plural: 7allaaqiin
	- Wurzel: 7-l-q
	- Hinweis: in Damaskus gesprochen „7allaa2“

- **kwaafeerat** (f.) – die Friseurin
	- كوافيرة
	- كوافيرَة
	- Hinweis: für einen Mann sagt man 7allaaq

- **5ayyaaT / 5ayyaaTat** (m. / f.) – der Schneider / die Schneiderin
	- خياط / خياطة
	- خَيّاط / خَيّاطَة
	- Plural: 5ayyaaTiin (m.), 5ayyaaTaatt (f.)
	- Wurzel: 5-y-T
	- Hinweis: 5ayyaaT für einen Mann, 5ayyaaTat für eine Frau

- **sawwaaq / sawwaaqat** (m. / f.) – der Fahrer / die Fahrerin
	- سواق / سواقة
	- سَوّاق / سَوّاقَة
	- Plural: sawwaaqiin (m.), sawwaaqaatt (f.)
	- Wurzel: s-w-q
	- Hinweis: sawwaaq für einen Mann, sawwaaqat für eine Frau. In Damaskus gesprochen „sawwaa2“

- **Tabbaa5 / Tabbaa5at** (m. / f.) – der Koch / die Köchin
	- طباخ / طباخة
	- طَبّاخ / طَبّاخَة
	- Plural: Tabbaa5iin (m.), Tabbaa5aatt (f.)
	- Wurzel: T-b-5
	- Hinweis: Tabbaa5 für einen Mann, Tabbaa5at für eine Frau

- **mudiir / mudiirat** (m. / f.) – der Direktor / die Direktorin, der Leiter / die Leiterin
	- مدير / مديرة
	- مُدير / مُديرَة
	- Plural: mudiiriin or mudaraa2 (m.), mudiiraatt (f.)
	- Hinweis: mudiir für einen Mann, mudiirat für eine Frau

- **sekerteer / sekerteerat** (m. / f.) – der Sekretär / die Sekretärin
	- سكرتير / سكرتيرة
	- سِكِرتير / سِكِرتيرَة
	- Plural: sekerteeriin (m.), sekerteeraatt (f.)
	- Hinweis: sekerteer für einen Mann, sekerteerat für eine Frau

- **Seedalii** (m.) – der Apotheker
	- صيدلي
	- صيدَلي
	- Plural: Seedaliyyiin
	- Hinweis: für eine Frau sagt man Seedalaaniyyet

- **Seedalaaniyyet** (f.) – die Apothekerin
	- صيدلانية
	- صيدَلانيِّة
	- Hinweis: für einen Mann sagt man Seedalii

- **muDiif / muDiifet** (m. / f.) – der Kellner / die Kellnerin
	- مضيف / مضيفة
	- مُضيف / مُضيفِة
	- Plural: muDiifiin (m.), muDiifaatt (f.)
	- Hinweis: muDiif für einen Mann, muDiifet für eine Frau

- **mwaDDHaf / mwaDDHafet** (m. / f.) – der Angestellte / die Angestellte
	- موظف / موظفة
	- مْوَظَّف / مْوَظَّفِة
	- Plural: mwaDDHafiin (m.), mwaDDHafaatt (f.)
	- Hinweis: mwaDDHaf für einen Mann, mwaDDHafet für eine Frau. In Damaskus gesprochen „mwazzaf“

- **mikaaniikii** (m.) – der Mechaniker
	- ميكانيكي
	- ميكانيكي

- **najjaar** (m.) – der Tischler
	- نجار
	- نَجّار

- **kaateb** (m.) – der Schriftsteller
	- كاتب
	- كاتِب
	- Wurzel: k-t-b

- **qaare2** (m.) – der Leser
	- قارئ
	- قارِئ
	- Wurzel: q-r-2

- **3aalem** (m.) – der Gelehrte, der Wissenschaftler
	- عالم
	- عالِم
	- Wurzel: 3-l-m

- **laa3eb** (m.) – der Spieler
	- لاعب
	- لاعِب
	- Wurzel: l-3-b

- **sabbaa7** (m.) – der Schwimmer, der Schwimmlehrer
	- سباح
	- سَبّاح
	- Wurzel: s-b-7

- **raqqaaS** (m.) – der Tänzer
	- رقاص
	- رَقّاص
	- Wurzel: r-q-S

- **shughl** (m.) – die Arbeit
	- شغل
	- شُغل
	- Wurzel: sh-gh-l
	- Hinweis: in Damaskus gesprochen „sheghel“
