# 2iDaafet

**Grundidee:** Man kann zwei unbestimmte Nomen kombinieren, um etwas genauer zu beschreiben (ähnlich wie ein Adjektiv). Das zweite Nomen beschreibt das erste näher. Das nennt man **"2iDaafet"**. Das ist dem deutschen Kompositum sehr ähnlich, nur anders aufgebaut.

**Aussprache-Änderung:** Endet das erste Wort auf -et/-at (taa2 marbuuTat), wird das t ausgesprochen. Ein -at wird dabei zu -et: shantat → shantet madraset.
